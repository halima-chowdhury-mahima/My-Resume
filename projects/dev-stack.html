Dev Stack — Technology Explorer

01 / OVERVIEW

About the project.

Dev Stack is a responsive web application designed to help users explore modern development technologies and organize their preferred technology stack.

Technology information is loaded from JSON data and displayed through responsive, reusable technology cards.

Users can select technologies and add them to their stack while receiving instant feedback through toast notifications.

## 📌 About the Project

This project is a personal **Resume and Portfolio Website** created to present my professional profile, technical skills, educational background, and web development journey in a clean and modern way. The main goal of this website is to create a professional online presence where visitors can easily learn about me, explore my technical skills, view my work, and find different ways to get in touch with me. The website has been designed with a simple, elegant, and user-friendly interface, with a strong focus on readability, visual consistency, and responsive design. It includes dedicated sections for my introduction, technical skills, education, projects, and contact information, allowing the content to be organized clearly and professionally. The website is built using **HTML5, CSS3, and JavaScript**, along with Google Fonts and Font Awesome icons to enhance its visual appearance and user experience. This project also reflects my continuous learning journey as an aspiring Web Developer and demonstrates my interest in building modern, responsive, and user-friendly web experiences.

## ✨ Key Features

* **Responsive Design**
  The website is designed to provide a smooth and consistent experience across different screen sizes, including desktops, tablets, and mobile devices. The layout, typography, spacing, and image sizes automatically adapt according to the screen width.

* **Modern Hero Section**
  The homepage features a professional hero section that introduces me as an aspiring Web Developer. It includes my name, professional title, personal description, profile image, and clear buttons that allow visitors to quickly navigate to the Projects and Contact sections.

* **About Me Section**
  The About section provides a detailed introduction to my background, interests, and development journey. It highlights my passion for modern web technologies and my continuous effort to improve my technical and creative skills.

* **Technical Skills Showcase**
  The Skills section organizes my technical abilities into clear categories such as Frontend Development, Backend & Tools, and Design Tools. This makes it easier for visitors to understand the technologies and tools I am currently learning and working with.

* **Education Section**
  The Education section presents my academic background in a structured and professional format. It includes my current BBA studies in Finance & Banking as well as my HSC and SSC educational qualifications and academic results.

* **Project Showcase**
  The Projects section highlights my practical web development work. Each project contains a project title, description, and the technologies used, allowing visitors to quickly understand the purpose and technical implementation of my projects.

* **Smooth Navigation**
  The website provides smooth scrolling between different sections, creating a more comfortable and natural browsing experience. Visitors can easily move between Home, About, Skills, Education, Projects, and Contact sections.

* **Active Navigation State**
  JavaScript is used to provide an active state for navigation links. The selected navigation item receives a different style so that users can easily identify the section they are currently viewing.

* **Interactive Buttons**
  The hero section contains clear call-to-action buttons that guide visitors toward important areas of the website. Hover effects and transitions are used to make the buttons feel more interactive.

* **Contact Section**
  The Contact section provides essential information for connecting with me. It includes my email address, GitHub profile, and location so that visitors can easily find the appropriate communication method.

* **Social Media Links**
  The footer includes social and communication icons for platforms such as Facebook, LinkedIn, Instagram, email, and phone. These links provide convenient access to different communication channels.

* **Clean & Professional UI**
  The website uses a consistent color palette, typography, spacing, cards, buttons, shadows, and rounded corners to create a clean and professional visual appearance.

* **JavaScript Functionality**
  JavaScript adds interactive functionality to the website, including smooth navigation and active navigation states. This makes the overall website more dynamic and user-friendly.

* **Profile Image Integration**
  The hero section includes a dedicated profile image area with rounded corners, padding, and a subtle shadow effect. This creates a visually balanced and professional introduction.

* **Mobile-Friendly Layout**
  Responsive CSS media queries are used to adjust the website layout for smaller screens. Font sizes, image dimensions, spacing, and content arrangement are modified to maintain usability on mobile devices.

## ⚙️ Installation

Follow the steps below to run the project locally.

### 1. Clone the Repository

```bash
git clone https://github.com/halima-chowdhury-mahima/resume.git
```

### 2. Navigate to the Project Directory

```bash
cd resume
```

### 3. Open the Project

Open the project folder in **Visual Studio Code** or any preferred code editor.

## ▶️ How to Run

This is a frontend project, so no backend server or database setup is required.

### Using Live Server

* Open the project in Visual Studio Code.
* Open `index.html`.
* Right-click on the file.
* Select **Open with Live Server**.
* The website will open automatically in your browser.

### Using a Browser

You can also open the project directly by double-clicking the `index.html` file.
